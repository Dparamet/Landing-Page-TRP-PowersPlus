# Portfolio Images

Place portfolio/project images in this folder.

Recommended:

- Use `.webp` when possible.
- Use English filenames with no spaces, for example `factory-solar.webp`.
- Keep each image under about 500 KB when possible.
- Update the matching `coverImage.src` or `gallery[].src` value in `src/content/site.ts`.
- For each project, keep at least three gallery stages: `before`, `during`, and `after`.
